# Contributing

Thanks for your interest in contributing to this repository.

## How to contribute

- Open an issue before making a large change.
- Keep the notebooks clean, readable, and well-documented.
- Add comments or markdown explanations where the workflow is not obvious.
- Ensure code runs in a fresh environment before submitting a pull request.
- Keep results and visualizations reproducible when possible.

## Local setup

```bash
git clone https://github.com/basantbansal/deep-learning-projects.git
cd deep-learning-projects
python -m venv venv
source venv/bin/activate   # On Windows: venv\Scripts\activate
pip install -r requirements.txt
jupyter lab
```

## Pull request guidelines

- Use a clear title and summary for your PR.
- Include screenshots or results if relevant.
- Explain what changed and why.
- Keep the scope focused and easy to review.

We appreciate thoughtful improvements, fixes, and experiments.
